### Why Soft Data HRMS

| Domain | What it delivers |
| --- | --- |
| **People** | Employee directory, org structure, compensation packages & revision history |
| **Hiring** | Job openings, ATS pipeline, interviews, offers, hire-to-employee |
| **Absence** | Leave request / approve / balance against org policies + encashment |
| **Time** | Timesheets, optional attendance, OT & variable pay before payroll |
| **Payroll** | UAE runs, proration, payslip PDF branding, **WPS**, **EOS / gratuity** |
| **Documents** | Request → review → issue with expiry awareness |
| **Control** | Super Admin module enable/disable, SSO, company branding, audit |
